# etch-a-sketch
This project took me about 7 hours. I made an interactive drawing grid with JavaScript and CSS. The tricky parts were making the squares resize dynamically, making drawing only happen when the mouse is held down, and figuring out the opacity logic. Resetting the grid while keeping the last grid size also took some debugging. It was hard, but very educational and fun.
In this project, the newly used technologies were dynamic grid creation, mouse events, and CSS opacity transitions.
