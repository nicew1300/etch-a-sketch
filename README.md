# etch-a-sketch
Description:
Interactive drawing grid project built with JavaScript and CSS. Focused on dynamic element creation and state management.

Key Features:

Adjustable grid size with interactive drawing.

Progressive drawing opacity logic.

Reset functionality for grid while maintaining previous state.

Challenges & Learnings:

Dynamic DOM manipulation and CSS grid layout.

Logic for mouse tracking and opacity changes.

Reinforced problem-solving in JS with step-by-step debugging.
